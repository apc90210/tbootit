# Расширение Chrome «Техноребут Avito» (Manifest V3) — Версия 0.1.9

## Назначение
Локальная передача объявлений из обычного браузера Google Chrome на Windows в систему учета Техноребут без использования автоматизации, копирования cookies или паролей. Поддерживает безопасный импорт всех фотографий объявления с точной канонической дедупликацией по идентификатору физического снимка Avito.

## Инструкция по обновлению / установке в Google Chrome (Developer Mode)

1. Перейдите в панель управления Техноребут по адресу: `http://localhost:8011/avito/extension`
2. Нажмите кнопку **«Скачать расширение 0.1.9 (ZIP)»**.
3. Распакуйте скачанный ZIP-архив в новую папку на компьютере (убедитесь, что `manifest.json` находится непосредственно в распакованной папке).
4. Откройте Google Chrome и перейдите по адресу: `chrome://extensions`
5. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).
6. Для надёжности **удалите** предыдущую версию и нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
7. Выберите распакованную папку версии 0.1.9. Расширение **«Техноребут Avito v0.1.9»** появится в списке.

## Порядок привязки (Pairing Flow)

1. Откройте окно расширения на любой странице Avito.
2. При отсутствии привязки статус отображает **«Сервер доступен»** (не «Подключен»), а в нижней части выводится форма привязки:
   - Текстовое поле ввода 6-значного кода: `[ 123456 ]`
   - Кнопка: `[ Подключить ]`
   - Кнопка «Передать объявление в Техноребут» заблокирована.
3. В панели Техноребут `http://localhost:8011/avito/extension` нажмите **«Создать новый код подключения»**.
4. Скопируйте 6-значный код и введите его в поле окна расширения.
5. Нажмите **«Подключить»**.
6. Расширение зафиксирует токен и сменит статус на **«Расширение привязано»** (зеленый бэдж).
7. Кнопка **«Передать объявление в Техноребут»** станет активной.
