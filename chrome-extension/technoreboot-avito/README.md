# Расширение Chrome «Техноребут Avito» (Manifest V3)

## Назначение
Локальная передача объявлений из обычного браузера Google Chrome на Windows в систему учета Техноребут без использования автоматизации, копирования cookies или паролей.

## Инструкция по установке (Developer Mode)

1. Откройте панель управления Техноребут по адресу: `http://localhost:8011/avito/extension`
2. Нажмите кнопку **«Скачать расширение (ZIP)»**.
3. Распакуйте скачанный ZIP-архив в удобную папку на компьютере.
4. Откройте Google Chrome и перейдите по адресу: `chrome://extensions`
5. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).
6. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
7. Выберите папку с распакованным расширением `technoreboot-avito`.

## Порядок привязки (Pairing)

1. В Техноребут на странице `http://localhost:8011/avito/extension` нажмите **«Создать новый код подключения»**.
2. Скопируйте 6-значный код (например `483921`).
3. В браузерной панели Chrome нажмите на иконку расширения **«Техноребут Avito»**.
4. Вставьте 6-значный код в поле подключения и нажмите **«Подключить»**.
5. Расширение отобразит статус **«Подключен»**.

## Передача объявления в Техноребут

1. В обычном Google Chrome откройте ваше объявление на сайте `https://www.avito.ru/`.
2. Нажмите на иконку расширения **«Техноребут Avito»**.
3. Нажмите кнопку **«Передать объявление в Техноребут»**.
4. В Техноребут создастся/обновится карточка товара (`Product`) и привяжется Avito ID.
