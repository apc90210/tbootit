# TECHNOREBOOT — Резервное копирование и Восстановление (Backup / Restore)

Механизм полного автономного резервного копирования и восстановления системы ТехноРебут (Stage 07B-R1).

---

## 1. Быстрый старт для Владельца (Owner Quickstart)

### Создать полную резервную копию:
```cmd
cd /d C:\tbootit
backup\backup_full.cmd
```
*Результат:* Единый архив вида `C:\tbootit\backups\TECHNOREBOOT_BACKUP_YYYY-MM-DD_HHMMSS.zip`.  
Этот файл можно скопировать на флешку или внешний жесткий диск для безопасного хранения вне сервера.

Также можно указать произвольную папку назначения:
```cmd
backup\backup_full.cmd "D:\TechnorebootBackups"
```

---

### Восстановить систему из резервной копии:
```cmd
cd /d C:\tbootit
backup\restore_full.cmd "C:\tbootit\backups\TECHNOREBOOT_BACKUP_2026-09-08_142812.zip"
```
*(Если запустить без параметров, скрипт автоматически предложит самый свежий бэкап из папки `backups/`).*

Для автоматического восстановления без запроса подтверждения (например, в скриптах):
```cmd
backup\restore_full.cmd "C:\tbootit\backups\TECHNOREBOOT_BACKUP_2026-09-08_142812.zip" --yes
```

## 2. Что входит в резервную копию

Архив полностью автономен и включает в себя все персистентные данные, необходимые для 100% поднятия системы с нуля:

1. **База данных SQLite (`database/`):**
   - `technoreboot.db`: Транзакционно-согласованный бинарный снимок базы (сделанный через встроенный API `sqlite3.Connection.backup()`).
   - `technoreboot_dump.sql`: Логический текстовый SQL-дамп всех таблиц и данных (`.iterdump()`), гарантирующий восстановление на любой версии SQLite.
2. **Медиа-файлы и фотографии товаров (`storage/`):**
   - Все загруженные фотографии товаров, деталей и ремонтов из `data/storage/`.
3. **Безопасность и mTLS PKI (`auth/`):**
   - Корневой удостоверяющий центр: `ca/ca.crt`, `ca/ca.key`.
   - Сертификаты и ключи шлюза: `server/server.crt`, `server/server.key`.
   - Сертификаты Владельца: `certificates/owner.crt`, `owner.key`, `owner.p12`.
   - Сертификаты пользователей: все сгенерированные `.crt`, `.key`, `.p12` клиентов.
   - Реестр доступа: `registry.json` со всеми отпечатками, статусами и записями отозванных (REVOKED) сертификатов.
   - Пароль владельца: `owner_password.txt`.
4. **Модуль Авито (`avito-module/`):**
   - Объявления, профили, токены расширения браузера и история парсинга.
5. **Конфигурация (`config/`):**
   - Файл `.env` (если настроен).
6. **Манифест бэкапа (`manifest.json`):**
   - Точное время создания (UTC).
   - Хеш коммита Git и ветка.
   - Статистика таблиц базы и количество записей.
   - SHA-256 отпечатки CA и сертификата Владельца.
   - Количество сертификатов и список отозванных.

## 3. Алгоритм восстановления и безопасность

1. **Строгая пред-валидация (Pre-Validation):**
   До остановки сервисов и до изменения каких-либо файлов скрипт проверяет целостность zip-архива, структуру `manifest.json`, наличие базы данных и ключей CA/Owner. Если бэкап поврежден — восстановление немедленно завершается с ошибкой, а текущие данные остаются нетронутыми.
2. **Защита от случайной перезаписи:**
   Скрипт требует явного подтверждения (`yes`), выводя предупреждение о перезаписи данных.
3. **Штатная остановка контейнеров:**
   Сервисы (`core`, `admin-shell`, `gateway`, `avito-module`, `inventory-sales-module`, `repairs-module`) останавливаются для исключения блокировок файлов.
4. **Атомарная распаковка:**
   Данные восстанавливаются в соответствующие папки `data/`.
5. **Запуск и проверка здоровья (Healthcheck):**
   Стек запускается (`docker compose up -d`), скрипт опрашивает endpoint `/health` до подтверждения статуса 200 OK.
6. **Проверка аутентичности:**
   Сверяются отпечатки восстановленного CA и сертификата Владельца с манифестом бэкапа. Владелец продолжает входить со своим существующим сертификатом без перевыпуска.

## 4. Сценарий: Полная потеря сервера (Disaster Recovery)

Если сервер вышел из строя, для восстановления на новом компьютере:

1. Установите Git, Docker Desktop и Python 3 на новый компьютер.
2. Склонируйте репозиторий:
   ```cmd
   git clone https://github.com/apc90210/tbootit.git C:\tbootit
   cd /d C:\tbootit
   ```
3. Скопируйте ваш бэкап `TECHNOREBOOT_BACKUP_....zip` на новый компьютер (например, в `C:\tbootit\backups\`).
4. Запустите восстановление:
   ```cmd
   backup\restore_full.cmd "C:\tbootit\backups\TECHNOREBOOT_BACKUP_....zip"
   ```
5. После завершения откройте админ-панель Владельца по mTLS:
   ```text
   https://localhost:8443/admin-shell/
   ```
   Ваш установленный сертификат Владельца сразу же авторизуется, все товары, фото и история будут на месте.
