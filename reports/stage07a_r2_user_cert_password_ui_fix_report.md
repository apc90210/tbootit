# Отчёт об исправлении и верификации: Stage 07A-R2
## User Certificate Password UX Fix

### 1. Выявленный дефект
В интерфейсе выпуска сертификатов `/certificates` сгенерированный одноразовый пароль для `.p12` скрывался через 1.5 секунды из-за встроенного таймера `setTimeout(() => { window.location.reload(); }, 1500)`. Владелец не успевал сохранить пароль, что делало невозможным установку сертификата на клиентские рабочие места.

---

### 2. Реализованное исправление
1. В шаблоне `admin-shell/app/templates/certificates.html`:
   - Убран принудительный таймер перезагрузки.
   - Реализован модальный диалог (`#certResultModal`), который остаётся на экране до явного нажатия кнопки «Закрыть».
   - Добавлены элементы:
     - Заголовок `Сертификат выпущен`
     - Название сертификата
     - Поле отображения пароля и кнопка `[ Копировать ]` (с подтверждением «✓ Скопировано»)
     - Ссылка/кнопка `[ Скачать сертификат .p12 ]`
     - Ссылка/кнопка `[ Скачать пароль .txt ]`
     - Кнопка `[ Закрыть ]` для закрытия окна и обновления таблицы.
2. В бэкенде `admin-shell/app/auth_manager.py` и `admin-shell/app/main.py`:
   - Пароли обычных пользователей исключены из `registry.json`.
   - Добавлен временный in-memory буфер `_temp_passwords` и эндпоинт `GET /admin-api/certificates/{cert_id}/password.txt` (доступен только для OWNER).
   - Удалены все устаревшие пароли из существующего файла `registry.json`.
