# Отчет о внедрении: Массовые (Batch) операции в каталоге товаров

**Дата:** 2026-09-11  
**Статус:** Готово к приёмке Владельцем (Browser-Only Acceptance)  
**Ветка:** \main\  

---

## 1. Что реализовано

По запросу Владельца в каталог товаров (\/inventory/products\) добавлены групповые операции с объединенным блоком управления:

1. **Множественный выбор чекбоксами**:
   - Чекбокс в шапке таблицы (\#select-all-products\) выделяет/снимает все товары на странице.
   - Чекбокс у каждого товара в таблице (\.product-select-cb\).
   - Поддержка быстрого диапазонного выделения через **Shift + Click**.
   - Синхронизация состояния «выделено частично» (\indeterminate\).

2. **Плавающая панель управления (\#batch-actions-bar\)**:
   - Автоматически всплывает при выделении хотя бы одного товара.
   - Показывает точный счетчик: \Выбрано: N товаров\.
   - Кнопка **Снять выбор**.

3. **Единый блок статуса и места хранения с ОДНОЙ кнопкой «Применить»**:
   - Селектор статуса: выбор целевого статуса или \— Статус (не менять) —\ по умолчанию.
   - Селектор места хранения: выбор целевой локации или \— Место (не менять) —\ по умолчанию.
   - **Одна кнопка «Применить» (\#btn-batch-apply-changes\)**:
     - Если заданы оба поля — оба обновляются одновременно в одной транзакции Core API.
     - Если задан только статус — обновляется только статус, место хранения не затрагивается.
     - Если задано только место хранения — обновляется только место, статус не затрагивается.
     - Если ни одно поле не выбрано — система выводит предупреждение и не отправляет пустой запрос.

4. **Массовая печать ценников 58x40 мм**:
   - Кнопка **Печать ценников (58×40)**.
   - Открывает превью ценников выбранных товаров с штрихкодами (SVG Code128).
   - Правильная верстка для термопринтера (разрыв страниц \page-break-after: always\).
   - Автоматический запуск диалога печати браузера (\window.print()\).

5. **Массовое добавление в чек (Продажа)**:
   - Кнопка **Продать (в корзину)**.
   - Все выбранные доступные к продаже товары автоматически добавляются в корзину кассы (\/inventory/cart\).
