# Stage 07F-R1-R1 — Отчет: Исправление извлечения объявлений из реального профиля Авито и устранение ложного успеха

**Дата:** 10 сентября 2026 г.  
**Версия плагина:** `0.2.49` (ранее `0.2.48`)  
**Статус этапа:** УСПЕШНО ЗАВЕРШЕН (FINAL_STATUS: SUCCESS)  
**Ветка:** `main`

---

## 1. Резюме проблемы и достигнутого результата

В ходе реального тестирования расширения версии `0.2.48` на странице личного кабинета продавца Авито (`/profile/items`) возникла критическая проблема:
1. Расширение определяло страницу как список объявлений, однако находило ровно **0 объявлений**.
2. В интерфейсе всплывающего окна отображалось: «Найдено объявлений: 0. Страница 1 из 1».
3. При нажатии на кнопку запуска пакетного импорта плагин выводил ложное позитивное сообщение с зеленой галочкой:
   `✓ Импорт успешно завершен! Страниц обработано: 1, объявлений: 0`.

### Что исправлено:
- **Устранен ложный успех:** Если объявлений на распознанной странице списка найдено 0, плагин **никогда** не выводит зеленый успешный статус. Вместо этого выводится четкое желтое предупреждение (`msg-warning`), кнопки импорта блокируются, и пользователю предлагается ссылка «Повторить поиск».
- **Многоуровневое (Layered) извлечение карточек:** Теперь поддерживается не только поисковая выдача каталога (`iva-item-root`), но и личный кабинет (`/profile/items`, `item-root`, `item-snippet`, dynamic React modules), а также публичный профиль продавца (`/user/.../profile`).
- **Пуленепробиваемый резервный поиск (Anchor Fallback):** Если контейнеры карточек не распознаны селекторами классов, плагин автоматически сканирует все ссылки `a[href]`, содержащие ID объявления Авито, поднимается вверх по DOM-дереву (до 10 уровней) для нахождения границ карточки и извлекает название, цену, фото и статус.
- **Устойчивость к отсутствующей цене:** Объявления без указанной цены (или со статусом «Цена договорная») больше не отбрасываются; цена корректно сохраняется как `null`.
- **Строгая дедупликация:** Объявления внутри одной страницы гарантированно дедуплицируются по `avito_id`, даже если в карточке содержится несколько ссылок (на фото, заголовок, статистику).
- **Асинхронное ожидание рендеринга:** Внедрен механизм `MutationObserver` с периодическим опросом каждые 250 мс (с ограничением ожидания до 10 секунд). Плагин не возвращает 0 объявлений преждевременно, пока React SPA гидратирует карточки на странице.
- **Версионность:** Плагин обновлен до версии **`0.2.49`** во всех манифестах, интерфейсах, бэкенд-эндпоинтах и собран в установочный ZIP-архив.

## 2. Доказательство первопричин сбоя в версии 0.2.48

| № | Фактор сбоя | Механизм проявления в v0.2.48 | Исправление в v0.2.49 |
|---|---|---|---|
| 1 | **Селекторы были рассчитаны только на поисковую выдачу** | Использовались `.iva-item-root`, `[data-marker="catalog-serp/item"]`, `.item-snippet`. В личном кабинете Авито (`/profile/items`) карточки имеют маркеры `[data-marker="item-root"]`, `[data-marker^="item-"]`, либо динамические React CSS-модули без `.iva-item-root`. Селектор находил 0 элементов. | Расширен охват селекторов Layer 1 (`[data-marker*="item"]`, `div[class*="snippet"]`, `styles-module-root-` и др.) + добавлен Layer 2 по ссылкам. |
| 2 | **Отсутствие fallback-стратегии по ссылкам** | Если селекторы контейнеров возвращали пустой NodeList, плагин сразу прекращал поиск. | Если контейнеры не найдены, Layer 2 собирает все ссылки `a[href]` с паттерном ID объявления Авито и находит карточку восхождением по DOM (`findCardContainerForAnchor`). |
| 3 | **Синхронное чтение DOM при открытии popup** | В момент клика на иконку плагина SPA Авито могло находиться в процессе подгрузки данных/гидратации. Синхронный опрос возвращал 0 элементов. | Добавлена функция `extractMyListingsDataAsync(maxWaitMs = 10000)`: если карточки уже есть — возврат мгновенный (0 мс), если нет — наблюдение через `MutationObserver` и опрос каждые 250 мс. |
| 4 | **Безусловный зеленый успех в bulk-импорте** | В блоке `finally` функции `bulkImportAllBtn` было прописано безусловное назначение класса `msg-success` и шаблон `✓ Импорт успешно завершен! Страниц: N, объявлений: M`. | Введена строгая проверка: если `totalProcessed === 0`, устанавливается класс `msg-warning`, текст «⚠️ Объявления не найдены», а зеленый статус не показывается. |

## 3. Архитектура и реализация решения

### 3.1. Регулярные выражения и извлечение ID Авито (`content.js`)
Функция `extractAvitoIdFromUrl(url)` поддерживает все форматы URL объявлений Авито:
- Слаг со знаком подчеркивания: `/moskva/tovary/videokarta_rtx_3070_1234567890` -> `1234567890`
- Query-параметры: `?itemId=1234567890` или `?item_id=1234567890` -> `1234567890`
- Пути вида `/item/1234567890`, `/items/1234567890`, `/obyavlenie/1234567890` -> `1234567890`
- Короткие ссылки: `/1234567890` -> `1234567890`
- Исключены системные страницы (профиль, отзывы, сообщения, настройки, помощь).

### 3.2. Восхождение по DOM-дереву (`findCardContainerForAnchor`)
Для каждой найденной ссылки на объявление алгоритм проверяет предков на глубину до 10 уровней:
1. Проверяет наличие характерных маркеров (`data-marker*="item"`, `data-marker*="snippet"`, `iva-item`, `ItemSnippet`).
2. Проверяет семантические теги `article`, `li`.
3. Ограничивает подъем при достижении глобальных контейнеров (`body`, `main`, `#app`, скролл-контейнеры списков).

### 3.3. Разбор полей карточки (`parseListingCardElement`)
- **Заголовок:** извлекается из `h3`, `[itemprop="name"]`, `[data-marker*="title"]`, `[class*="title-"]`, либо из текста ссылки / атрибута `title` / `aria-label`.
- **Цена:** извлекается регулярным выражением чисел из текста элементов с маркерами цен (`[data-marker*="price"]`, `[class*="price-"]`, `[itemprop="price"]`). При отсутствии цены сохраняется как `null` без отбрасывания товара.
- **Статус:** определяется автоматически («active» / «inactive») по признакам закрытия, снятия с публикации или текстам «Снято с публикации», «Продано», «Неактивно».
- **Фото:** превью извлекается из первого тега `img` внутри карточки (поддерживаются `src`, `data-src`, `srcset`).

### 3.4. Асинхронное ожидание (`extractMyListingsDataAsync`)
```javascript
// Возвращает промис с ожиданием до 10 секунд
async function extractMyListingsDataAsync(maxWaitMs = 10000) {
  const initial = extractMyListingsData();
  if (initial.items && initial.items.length > 0) return initial;
  // MutationObserver + polling 250ms до появления карточек или истечения таймаута
}
```

### 3.5. Защита интерфейса от ложного успеха (`popup.js`)
1. При открытии popup на странице `avito.ru` сразу отображается статус «🔍 Сканирование страницы...».
2. Если найдено 0 объявлений:
   - Блок `bulkDetectInfo` отображает предупреждающую плашку.
   - Обе кнопки «Импортировать все объявления» и «Импортировать текущую страницу» блокируются (`disabled = true`).
   - Отображается кликабельная ссылка `[Повторить поиск]`.
3. По завершении пакетного цикла:
   - Если импортировано 0 объявлений, статус получает класс `msg-warning`:
     `⚠️ Объявления не найдены. Проверьте, что список объявлений загрузился полностью. Страниц обработано: 1, объявлений: 0.`
   - Зеленый класс `msg-success` и формулировка «✓ Импорт успешно завершен!» исключены.

## 5. Пошаговая инструкция для Владельца (проверка только в браузере, без CLI)

Владельцу не требуется использовать терминал или командную строку. Все действия выполняются исключительно через веб-интерфейс браузера Google Chrome / Яндекс.Браузер.

### Шаг 1: Скачивание и распаковка обновленного плагина
1. Откройте страницу интеграции с Авито:  
   `https://localhost:8443/avito/extension` (или через закладку / меню «Интеграции» -> «Расширение Avito»).
2. Нажмите синюю кнопку **«Скачать расширение (ZIP, v0.2.49)»**.
3. Распакуйте скачанный zip-архив в удобную папку на компьютере (например, заменив файлы в папке `technoreboot-avito`).

### Шаг 2: Обновление плагина в браузере
1. В браузере откройте вкладку: `chrome://extensions/`
2. Убедитесь, что в правом верхнем углу включен **«Режим разработчика»** (Developer mode).
3. Найдите карточку расширения **«Technoreboot Avito Integration»**.
4. Нажмите круглую кнопку со стрелкой **«Обновить»** (Reload) на карточке расширения.
5. Убедитесь, что отображается версия: **`0.2.49`**.

### Шаг 3: Проверка на реальной странице профиля Авито
1. Перейдите на страницу ваших объявлений в личном кабинете Авито:  
   `https://www.avito.ru/profile/items` (или в публичный профиль продавца).
2. Нажмите на значок расширения Technoreboot на панели браузера.
3. **Что вы увидите:**
   - Если объявления загрузились, в блоке «Пакетный импорт профиля» сразу отобразится реальное количество найденных объявлений (например: `Найдено объявлений на странице: 15`).
   - Кнопки «Импортировать все объявления» и «Импортировать текущую страницу» станут активными (синими).
   - Если страница Авито еще грузится, плагин подождет появления карточек. Если карточек действительно нет, появится желтое предупреждение «Объявления не найдены» со ссылкой «Повторить поиск», а кнопки будут заблокированы. Зеленый статус успеха при 0 объявлений больше не появится!
4. Нажмите **«Импортировать текущую страницу»** (или «Импортировать все объявления»).
5. Наблюдайте за ходом импорта: счетчики будут увеличиваться по мере отправки карточек.
6. По завершении появится сообщение: `✓ Импорт успешно завершен! Страниц обработано: 1, объявлений: N`.

### Шаг 4: Проверка сохранения в номенклатуре Technoreboot
1. Откройте раздел «Склад и товары»:  
   `https://localhost:8443/inventory/products`
2. Убедитесь, что импортированные объявления появились в списке товаров.
3. Откройте карточку любого импортированного товара: все базовые данные (название, цена, статус, фото) на месте.
