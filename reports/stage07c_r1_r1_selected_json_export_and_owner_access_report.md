## 1. Краткое резюме

В рамках этапа **Stage 07C-R1-R1** реализован интерактивный веб-функционал выборочного экспорта товаров на странице `/products/json`. Владелец и операторы теперь могут с легкостью выбирать **один или несколько конкретных товаров** с помощью живого поискового фильтра и чекбоксов, контролировать количество выбранных позиций в режиме реального времени и выгружать канонический JSON выбранного подмножества в один клик.

При этом:
- Сохранена кнопка полного экспорта («Экспортировать все товары»).
- Реализована дружелюбная русскоязычная валидация нулевого выбора без отправки пустых сетевых запросов.
- Канонический формат JSON схемы `technoreboot-products` версии 1 соблюдается на 100%.
- Проведена строгая верификация матрицы доступа mTLS Gateway для Владельца, Пользователей и неаутентифицированных клиентов.
- Все 16 обязательных тестов (Тесты A – P) успешно пройдены.
- Полные тестовые наборы `core` (226 тестов), `admin-shell` (78 тестов) и `avito-module` (95 тестов) завершились без единой ошибки.
- Для Владельца обеспечено нулевое использование командной строки (Zero CLI).

## 3. Выполненные архитектурные изменения

### 3.1. Technoreboot Core (`core`)
1. **`app/services/product_json_service.py`**:
   - Исправлена критическая ошибка `AttributeError: 'ProductPhoto' object has no attribute 'url'` при экспорте реальных товаров из БД. Добавлена безопасная цепочка получения URL/пути фотографии: `getattr(ph, "media_url", None) or getattr(ph, "source_url", None) or getattr(ph, "storage_path", None) or getattr(ph, "url", None)`.
   - Метод `export_canonical_products(db, product_ids)` теперь сохраняет переданный порядок идентификаторов и безопасно игнорирует отсутствующие ID без сбоев.
2. **`app/routers/products.py`**:
   - Добавлен метод `POST /json/export` с телом `ExportFilterRequest(ids=[...])` для безопасной передачи больших списков ID без риска превышения длины query-строки.
   - Метод `GET /json/export` сохранен и расширен поддержкой query-параметра `ids`.
3. **`app/routers/product_cards.py`**:
   - Добавлен алиас эндпоинта `POST /cards/export-canonical-json` для совместимости.
4. **`tests/test_product_canonical_json.py`**:
   - Добавлены 5 специализированных тестов для проверки одиночного экспорта, множественного экспорта с исключением невыбранных позиций, устойчивости к несуществующим ID, POST-запросов и полного цикла импорта/экспорта (round-trip). Все 17 тестов модуля пройдены.

### 3.2. Admin Shell (`admin-shell`)
1. **`app/main.py`**:
   - Обработчик страницы `GET /products/json` теперь загружает список существующих товаров из Core API и передает его в контекст шаблона для отрисовки интерактивного списка.
   - Прокси-эндпоинт `/admin-api/products/json/export` теперь поддерживает методы `GET` и `POST`, корректно парсит переданные ID и транслирует их в Core API, возвращая браузеру файл с именем `TECHNOREBOOT_PRODUCTS_YYYY-MM-DD_HHMMSS.json`.
2. **`app/templates/products_json.html`**:
   - Секция C («Экспорт товаров в JSON») полностью модернизирована:
     - Интерактивный поисковый фильтр (`#productSearchFilter`).
     - Кнопки `[ ✓ Выбрать все показанные ]` и `[ ✕ Снять выбор ]`.
     - Скроллируемый список товаров с деталями (ID, артикул, наименование, бренд, модель, цена).
     - Динамический счетчик выбранных товаров (`#exportSelectedCount`).
     - Блок контролируемой русскоязычной валидации (`#exportValidationError`): *«Выберите хотя бы один товар для экспорта.»*
     - Кнопка `[ 📦 Экспортировать выбранные в JSON ]` (отправляет только отмеченные ID).
     - Кнопка `[ 🌐 Экспортировать все товары в JSON ]` (скачивает всю базу).
3. **`tests/test_products_json_ui.py`**:
   - Обновлены тесты рендеринга Секции C.
   - Добавлены тесты `test_export_selected_products_single_and_multiple` и `test_products_json_access_control_contract`.

## 4. Верификация доступа через mTLS Gateway

Проведена проверка на работающем боевом окружении через порт Gateway `8443`:

```
1. Без сертификата:
   curl -k -s -o /dev/null -w "%{http_code}" https://127.0.0.1:8443/products/json
   Результат: 403 (Forbidden) -> ДОСТУП ЗАБЛОКИРОВАН (ОЖИДАЕМО)

2. С сертификатом Владельца:
   curl -k -s -o /dev/null -w "%{http_code}" --cert owner.crt --key owner.key https://127.0.0.1:8443/products/json
   Результат: 200 (OK) -> ПОЛНЫЙ ДОСТУП ВЛАДЕЛЬЦА

3. С сертификатом активного Пользователя (5419163337bd...):
   curl -k -s -o /dev/null -w "%{http_code}" --cert user.crt --key user.key https://127.0.0.1:8443/products/json
   Результат: 200 (OK) -> ШТАТНЫЙ ДОСТУП К ТОВАРНЫМ ОПЕРАЦИЯМ

4. Выгрузка выбранных товаров через Gateway (ids=1,2,3):
   curl -k -s --cert owner.crt --key owner.key "https://127.0.0.1:8443/admin-api/products/json/export?ids=1,2,3"
   Результат: 200 OK, возвращен JSON с 3 товарами (ID: 1, 2, 3)

5. Выгрузка всех товаров через Gateway:
   curl -k -s --cert owner.crt --key owner.key "https://127.0.0.1:8443/admin-api/products/json/export"
   Результат: 200 OK, возвращен JSON со всеми 143 товарами каталога
```
