## 1. Задача
Реализовать указание Владельца из голосового сообщения:
> «Сделай пожалуйста, чтобы при нажатии 'Отчёты' сразу текущая неделя была активна, то есть сразу выводила просто кнопка текущая неделя, отчёт за текущую неделю, а потом уже остальные кнопки это уже отдельно нажимались. По умолчанию чтобы так было.»

---

## 2. Что выполнено
1. В маршрутизаторе `inventory-sales-module/app/routers/reports.py`:
   - Изменено поведение по умолчанию при отсутствии параметров: `period` теперь устанавливается в `"week"` (вместо произвольного диапазона с начала года).
   - Core API вызывается с `period="week"`, возвращая сводку за дни текущей недели (с понедельника по текущий день).
2. В шаблоне `inventory-sales-module/app/templates/reports_sales.html`:
   - Кнопка недели оформлена с атрибутом `title="Текущая неделя"` и активируется (`active`) по умолчанию при клике на «Отчёты».
   - Поля дат формы автоматически синхронизируются с датами понедельника текущей недели и сегодняшнего дня.
   - Остальные быстрые фильтры («Сегодня», «Месяц», «Год») и ручной диапазон сохраняют полную работоспособность.
3. Обновлены тесты в `inventory-sales-module/tests/test_sales_reports_ui.py` для подтверждения вызова Core API с `period="week"` и активности кнопки недели при дефолтном открытии страницы.
4. Создан и выполнен скрипт сквозной E2E-проверки `scripts/verify_reports_default_to_current_week_live.py` через Gateway 8443 (mTLS) с сертификатом владельца.
