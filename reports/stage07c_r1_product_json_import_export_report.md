## 1. Контекст и выполненные цели

Владелец системы требовал надежный, единый способ пакетного и штучного добавления товаров в систему ТехноРебут через понятный русскоязычный веб-интерфейс без использования командной строки, а также возможность автоматической генерации промпта для нейросетей (ChatGPT, Claude, Gemini, DeepSeek и др.) для преобразования произвольных прайсов, накладных и списков в канонический формат системы.

### Выполненные задачи:
1. **Каноническая версионированная схема данных (`technoreboot-products`, `version: 1`):**
   - Реализована в `core/app/services/product_json_service.py`.
   - Поддерживает один или несколько товаров в массиве `products`.
   - Обратная совместимость с одиночным форматом карточек (`source: chatgpt`).
   - Безопасная валидация цен, названий и обязательных структурных элементов.
2. **Безопасная политика дубликатов и обновлений:**
   - Передан `id` и товар найден в БД — выполняется обновление (`UPDATE`).
   - Передан `id`, но товар не найден — пропуск с понятной ошибкой (`Товар с ID ... не найден`).
   - `id` отсутствует, но передан существующий `sku` — пропуск во избежание порчи данных (`Товар с артикулом '...' уже существует`).
   - `id` отсутствует, `sku` новый или пустой — создание (`CREATE`) с автогенерацией `PRD-YYYYMMDD-XXXXXX`.
3. **Сохранение целостности (Round-trip Fidelity):**
   - Экспортированный JSON при повторном импорте обновляет товары по их `id` без дублирования.
   - Специфические характеристики категорий (ноутбуки, принтеры, системные блоки) сохраняются и связываются с динамической схемой атрибутов Авито.
   - Фотографии опциональны (`photos: []` или опущены).
4. **Русскоязычный веб-интерфейс в `admin-shell` (`/products/json`):**
   - **Секция A (AI-промпт):** системный промпт с правилами форматирования и примерами, кнопка копирования в буфер с всплывающим уведомлением, кнопка скачивания файла `technoreboot_ai_prompt.txt`.
   - **Секция B (Импорт):** Drag-and-drop область, выбор файла `.json`, текстовая область для ручной вставки JSON, счетчики (Создано / Обновлено / Пропущено), детальная таблица результатов с артикулами и описанием ошибок.
   - **Секция C (Экспорт):** кнопка выгрузки всего каталога в файл `TECHNOREBOOT_PRODUCTS_YYYY-MM-DD_HHMMSS.json`.
5. **Единая навигация:**
   - Пункт меню «JSON импорт / экспорт» добавлен в шапку всех страниц Admin Shell (`index.html`, `backups.html`, `certificates.html`, `avito_extension.html`, `products_json.html`).
   - Корректный порядок регистрации маршрутов FastAPI в `admin-shell/app/main.py`: `GET /products/json` зарегистрирован до `GET /products/{product_id}` для исключения 422 HTTP ошибок.
