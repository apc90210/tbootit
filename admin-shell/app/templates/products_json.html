ТЕХНОРЕБУТ — JSON ИМПОРТ И ЭКСПОРТ ТОВАРОВ

Единый интерфейс для пакетного наполнения каталога с помощью любых современных нейросетей (ChatGPT, Claude, DeepSeek, Gemini, Qwen), импорта файлов с сохранением характеристик категорий Avito и создания канонических резервных выгрузок каталога.

🤖 Секция А: Генератор промпта для искусственного интеллекта (ИИ)

Скопируйте этот готовый системный промпт и передайте его любой нейросети вместе с текстом, прайс-листом или описанием ваших товаров. Нейросеть сформирует строго валидный JSON в каноническом формате Техноребута.

⬇️ Скачать промпт (.txt)
ℹ️ Справка: канонический формат JSON Техноребута (версия 1)

Корневой объект содержит "format": "technoreboot-products", "version": 1 и массив "products": [...].

  • Обязательные поля товара: title (название товара), price_rub (число ≥ 0).
  • Политика идентификации:
    • Если передан id: обновляется существующий товар с этим ID.
    • Если id не передан: создается новый товар. Артикул sku генерируется автоматически, если не указан. Если указан уже занятый sku без id, запись будет безопасно пропущена во избежание дубликатов.
  • Характеристики (Avito): словарь characteristics (например, {"Процессор": "Intel Core i5", "Объем оперативной памяти": "16 ГБ"}) сохраняется в типизированные атрибуты категории Avito.
  • Фотографии: поле photos является полностью опциональным (может быть пустым массивом [] или отсутствовать).
