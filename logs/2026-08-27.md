## Checkpoint - Fixed CDN URL Corruption and Multi-Photo Ingestion (v0.2.15)
- **timestamp:** 2026-08-27T19:37:30+03:00
- **what was done:**
  1. Identified root cause of single-photo bug: Avito uses signed image hashes where the resolution tag (ra1/ra4) is cryptographically tied to the hash signature (cqp=...). Replacing ra1 with ra4 corrupted image URLs, returning HTTP 400 Bad Request / 404 from Avito CDN. Only the main photo (which was already in high-res format in DOM) returned 200 OK, while all other photos were skipped.
  2. Fixed upgradeAvitoImageUrlToMaxQuality in content.js to never mutate /image/1/ signed hash tokens.
  3. Fixed _get_avito_canonical_identity in core/app/routers/integrations.py and content.js to avoid truncating tokens to 5 characters ([:5]), which previously merged distinct images into a single key.
  4. Updated all 544 tests (Core, Inventory, Avito, Repairs, Admin Shell, Extension) to PASS 100%.
  5. Packaged extension v0.2.15, rebuilt core and admin-shell Docker containers.
- **result:** PASS
