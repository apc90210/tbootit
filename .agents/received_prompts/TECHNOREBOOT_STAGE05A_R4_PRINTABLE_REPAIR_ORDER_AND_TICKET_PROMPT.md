# 1. Требование владельца

Нужен печатный документ, похожий по структуре на предоставленный бумажный образец:

```text
- наряд-заказ на ремонт;
- автоматически заполненные данные клиента;
- автоматически заполненные данные предприятия;
- автоматически заполненные данные ремонта и устройства;
- отрывной талон;
- подробные условия ремонта, диагностики, хранения и гарантии;
- подписи клиента и сотрудника;
- печать на A4.
```

Образец используется:

```text
как ориентир по структуре;
как источник условий ремонта и диагностики;
как источник текста согласия и выдачи.
```

Образец НЕ используется как источник устаревших реквизитов предприятия.

# 2. Критическое правило: ничего не придумывать

Запрещено добавлять данные, которых нет:

```text
в Core;
в RepairOrder;
в Organization Settings;
в предоставленном тексте условий.
```

Не придумывать:

```text
ОГРНИП;
второй телефон;
режим работы;
дополнительный адрес;
сайт;
email предприятия;
банковские реквизиты;
ФИО сотрудника, если assigned_to пуст;
стоимость ремонта;
список работ;
список деталей;
срок гарантии;
номер гарантийного талона;
диагностическое заключение;
условия гарантии, которых нет в образце;
юридические формулировки от себя.
```

Если поля нет в системе:

```text
не печатать его;
не оставлять фиктивную строку;
не подставлять текст из старого образца.
```

# 5. Print route

Добавить в repairs-module:

```text
GET /repairs/{repair_id}/print
```

или согласованный эквивалент:

```text
GET /repairs/{repair_id}/print-order
```

Route получает данные только через Core HTTP API.

Прямой доступ к Core DB запрещен.

На карточке ремонта добавить кнопку:

```text
Печать наряд-заказа
```

Кнопка открывает печатную страницу в новой вкладке.

На печатной странице:

```text
кнопка «Печать»;
кнопка «Назад к ремонту»;
автоматический вызов window.print() допустим,
но не должен мешать ручному просмотру.
```

# 13. Подробные условия - текст из образца

## Пункт 1

```text
Оборудование с согласия Заказчика принимается на ремонт и оценку
ремонтопригодности без разборки и проверки неисправностей, без проверки
внутренних повреждений.

которые могут быть обнаружены в оборудовании при его техническом
```

## Пункт 2

```text
Оборудование принимается на ремонт и оценку ремонтопригодности без
аксессуаров, кроме случаев, когда это необходимо для выполнения ремонта
или оценки ремонтопригодности.

Такой случай фиксируется в Наряд-заказе дополнительно.

Исполнитель не несет ответственности за сохранность переданных
устройств при отсутствии соответствующей записи в Наряд-заказе.
```

## Пункт 3

```text
Исполнитель ставит в известность Заказчика, что во время ремонта
оборудования, уже имеющего внешние повреждения, в том числе следы
попадания жидкости, ударов, трещины или следы неквалифицированного
ремонта, возможно появление новых дефектов.

Это может быть связано с проявлением скрытых дефектов, вызванных такими
повреждениями.

В связи с этим во время выполнения работ возможно ухудшение свойств
оборудования, вплоть до полного выхода из строя.

Заказчик предупрежден о такой возможности и осознает ее последствия.

При наступлении такого случая Заказчик не будет иметь претензий к
Исполнителю.
```

## Пункт 4

```text
Сервисный центр, далее «Исполнитель», не несет ответственности, если
после разборки, при оценке ремонтопригодности или ремонте состояние
аппарата ухудшится вследствие нарушения Заказчиком правил эксплуатации
аппарата.

К таким нарушениям относятся воздействие жидкости, механические
повреждения, использование техники не в соответствии с инструкцией и
другие подобные обстоятельства.

При неустойчивом проявлении заявленной неисправности или если
неисправность не проявляется, срок ремонта и диагностики может быть
увеличен.

Увеличение срока предварительно согласовывается с Заказчиком.
```

## Пункт 5

```text
Аппарат Заказчика принимается на ответственное хранение на весь срок
обслуживания, включая оценку ремонтопригодности и ремонт.

Готовый аппарат, аппарат с актом выполненных работ, аппарат, не
подлежащий ремонту, либо аппарат, согласованный без ремонта, должен быть
получен в течение 14 календарных дней после окончания ремонтных работ.

ремонтных работ.

При невыполнении этого требования взимается пеня в размере 50 рублей за
каждый день просрочки.

Выдача аппарата в таком случае производится только после уплаты всей
суммы задолженности Заказчика перед Исполнителем.

Аппараты, невостребованные в течение 3 месяцев, могут быть реализованы

После окончания указанного срока претензии по аппарату не принимаются.
```

# 14. Юридический текст - правило точности

Текст выше сформирован только на основании предоставленного владельцем образца.

Запрещено:

```text
самостоятельно добавлять новые юридические условия;
изменять суммы;
изменять сроки;
указывать гарантийный срок;
добавлять ссылки на законы;
добавлять штрафы;
добавлять согласие на рекламу;
добавлять передачу данных третьим лицам;
расширять ответственность клиента.
```

Не проводить автоматическую «юридическую корректировку» текста.

В отчете указать:

```text
LEGAL_TEXT_SOURCE: OWNER_PROVIDED_PAPER_SAMPLE
LEGAL_REVIEW_PERFORMED: false
OWNER_TEXT_ACCEPTANCE_REQUIRED: true
```

# 15. Точное отображение кириллицы

В бумажном образце видны фрагменты квадратов из-за проблемы со шрифтом.

В новой печати квадратов быть не должно.

Использовать доступный в контейнере шрифтовой стек:

```css
font-family:
  Arial,
  "DejaVu Sans",
  "Liberation Sans",
  sans-serif;
```

Не загружать и не коммитить сторонние font files.

Проверить:

```text
русские буквы;
кавычки;
тире;
номер;
рубль;
Ф.И.О.;
все заголовки.
```
