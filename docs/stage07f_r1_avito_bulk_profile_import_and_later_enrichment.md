# Документация: Пакетный импорт объявлений Avito и последующее обогащение данных (Stage 07F-R1)

## 1. Назначение и контекст

Этап **Stage 07F-R1** реализует двухфазный сценарий наполнения базы товаров Техноребут из профиля или списка объявлений Avito через браузерное расширение Chrome:
1. **Фаза 1 (Пакетный первичный импорт)**: Владелец открывает страницу своего профиля или списка объявлений на `avito.ru` и нажимает кнопку **«Импортировать все объявления»** (или «Импортировать текущую страницу»). Расширение извлекает легковесные данные карточек со страницы (Avito ID, ссылку, название, цену, статус, город/адрес и фото-превью) и автоматически перелистывает страницы пагинации, последовательно передавая данные в Техноребут.
2. **Фаза 2 (Последующее обогащение данных)**: Позже Владелец открывает любое отдельное объявление на `avito.ru` и нажимает **«Доимпортировать данные»**. Расширение выполняет глубокое сканирование карточки (описание, характеристики, фото в оригинальном качестве) и обновляет существующий товар без создания дубликатов.

## 2. Архитектура и принципы целостности данных

### 2.1 Идемпотентность и предотвращение дубликатов
- Связка между объявлением Avito и товаром Техноребут осуществляется через внешнюю связь `ProductExternalListing` по уникальному полю `external_item_id` (Avito ID).
- При пакетном импорте создаётся товар в статусе `draft` и привязывается `external_item_id`.
- При повторном пакетном импорте или при переходе в карточку объявления для обогащения Core находит уже существующую запись `ProductExternalListing` и обновляет исходный товар (`product_id`).
- Формула гарантии: **Пакетный импорт + Пакетный импорт + Обогащение = 1 товар** (0 дубликатов).

### 2.2 Неразрушающее сохранение данных (Data Protection Guarantee)
В Core API (`core/app/routers/integrations.py`):
- Если при обновлении приходит пакетный легковесный запрос, в котором `description` отсутствует (`None` или пустой), то существующее подробное описание `product.avito_description` **не затирается**.
- Приходящие параметры (`parameters`) объединяются с уже сохранёнными характеристиками (`existing_params.update(incoming)`), благодаря чему легковесный импорт с адресом не стирает процессор, видеокарту, память и другие характеристики.
- Если в запросе цена не указана, сохраняется прежняя `source_price`.

## 3. Компоненты системы и изменения

### 3.1 Core API (`core/app/routers/integrations.py`)
- Метод `import_avito_item`:
  - Добавлена логика слияния `existing_params` с входящими параметрами.
  - Добавлена защита от затирания `avito_description` пустыми значениями.
  - Сохранение `source_price` при `payload.price is None`.

### 3.2 Avito Module (`avito-module/app/routers/extension_bridge.py`)
- Добавлен роут `POST /extension/api/bulk-import` (и алиас `POST /extension/api/my-listings`):
  - Принимает пакет легковесных карточек `{ items: [...] }` либо структуру со списком объявлений.
  - Проверяет токен расширения `X-Extension-Token`.
  - Транслирует элементы в вызовы Core API `/api/integrations/avito/import-item`.
  - Отказоустойчивость: сбой одного элемента не прерывает обработку остальных карточек.
  - Возвращает агрегированную статистику: `{ status, total, created, updated, skipped, errors, error_count, results }`.

### 3.3 Chrome Extension (`chrome-extension/technoreboot-avito/`) — версия `0.2.48`
- `manifest.json`:
  - Версия увеличена до `0.2.48`.
  - Добавлено разрешение `"tabs"` для управления переходами по страницам пагинации.
- `content.js`:
  - Функция `extractPaginationInfo()`: определяет текущую страницу, общее число страниц и ссылку на следующую страницу.
  - Функция `extractMyListingsData()`: парсит все карточки объявлений со страницы с поддержкой современных селекторов Avito.
  - Диспетчер сообщений: автоматически распознает страницы списков/профиля (`my_listings`) и страницы отдельных объявлений (`listing`).
- `popup.html` и `popup.css`:
  - Добавлен блок `#bulkSection` со счётчиками, кнопками «Импортировать все объявления», «Импортировать текущую страницу», кнопкой остановки `#bulkStopBtn` и раскрываемым списком ошибок.
  - В `#actionSection` кнопка получила контекстный лейбл **«Доимпортировать данные»**.
- `popup.js`:
  - Логика автоматического перелистывания страниц с ограничением `MAX_PAGES = 50`, фильтрацией уже обработанных `seenAvitoIds`, защитой от зацикливания `visitedUrls` и паузой между переходами.
  - Кнопка немедленной остановки цикла с сохранением уже импортированных данных.
  - Режим одиночной карточки для обогащения данных.
- `service_worker.js`:
  - Обработчик действия `bulk_import_batch` с передачей через прокси `admin-shell`.
