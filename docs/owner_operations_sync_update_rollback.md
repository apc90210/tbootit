# Панель управления операциями: Синхронизация, Обновление и Быстрый откат

## Обзор интерфейса `/system/operations`

Панель `/system/operations` предоставляет Владельцу системы ТехноРебут единый центр управления жизненным циклом серверного и локального окружений.

Доступ защищен:
- Только сертификатом Владельца (`is_owner=True`).
- Только при локальном запуске (Local DEV Sandbox). На сервере VDS страница и API заблокированы (`403 Forbidden`).

---

## 1. Диагностика здоровья VDS (VDS Health Preflight)

В верхней части панели расположен бейдж статуса сервера:
- **`HEALTHY` (Зеленый):** Сервер доступен по SSH и HTTPS, Docker в норме, все 6 контейнеров в статусе `healthy`, SQLite БД читаема (`quick_check = ok`), свободного места на диске > 500 MB.
- **`DEGRADED` (Желтый):** Сервер доступен по SSH, но один из контейнеров нездоров, либо порт HTTPS не отвечает, либо мало места на диске. Создание снимков и обновления **заблокированы** до устранения неисправности.
- **`UNREACHABLE` (Красный):** Сервер полностью недоступен по сети / SSH.

---

## 2. Карточка 1: Синхронизация данных (VDS -> LOCAL)
- Скачивает свежий снимок базы данных и фотографий с боевого сервера на локальную рабочую станцию DEV.
- Направление **строго одностороннее**: боевые данные VDS никогда не перезаписываются с локального компьютера.
- Перед применением локально создается аварийный бэкап в `.local-recovery/`.

---

## 3. Карточка 2: Обновление VDS (UPDATE VDS)
- Переносит проверенный локальный код в продакшен.
- Проверяет:
  1. Чистоту Git (`git status --porcelain`).
  2. Отправку коммитов в `origin/main` (`git push`).
  3. Совместимость схемы БД (DB Schema Guard).
  4. Здоровье VDS (Preflight).
  5. Создает Release Checkpoint (бэкап VDS + локальная копия + тэгирование образов).
- Выполняет сборку и перезапуск сервисов на VDS.
- При сбое автоматически откатывает код к предыдущей версии.

---

## 4. Карточка 3: Быстрый откат VDS (Fast Rollback)
- Позволяет Владельцу в один клик вернуть продуктивный сервер к предыдущей рабочей версии кода.
- **Бизнес-данные (продажи, товары, ремонты) НЕ затрагиваются.**
- Проверяет совместимость схемы базы данных перед переключением.
- Создает аварийный бэкап текущего состояния перед откатом.

---

## 5. Таблица: Последние точки восстановления VDS
Отображает список сохраненных контрольных точек (`.local-recovery/vds-releases/`):
- Время создания и ID точки.
- Предыдущий и целевой коммиты.
- Наличие и SHA-256 локальной копии бэкапа.
- Количество сохраненных товаров и файлов.
- Статус допустимости отката.
