# Документация: Отчёты по умолчанию за текущую неделю

## 1. Назначение

По запросу Владельца раздел «Отчёты» (`/inventory/reports/sales`) теперь по умолчанию открывается **с активным периодом «Текущая неделя»** (`period=week`).

Ранее при переходе по ссылке «Отчёты» из любого раздела меню открывался отчёт с начала текущего года (YTD), при этом ни одна из кнопок быстрых фильтров не подсвечивалась.

Теперь при открытии раздела:
- Сразу выводится отчёт по продажам за текущую неделю (с понедельника по текущий день).
- Кнопка «Неделя» (Текущая неделя) подсвечена активной (`active`).
- Поля выбора дат «С» и «По» автоматически заполняются датами понедельника текущей недели и сегодняшнего дня.
- Остальные кнопки («Сегодня», «Месяц», «Год») и ручной выбор диапазона дат остаются доступными для отдельного переключения.

---

## 2. Архитектурные изменения

В обработчике `sales_report` модуля `inventory-sales-module/app/routers/reports.py`:
- При отсутствии переданных query-параметров (`period is None`, `date_from is None`, `date_to is None`) параметр `period` устанавливается в `"week"`.
- Запрос направляется в Core API: `core_client.get_sales_report(period="week")`.
- Core API вычисляет границы текущей недели:
  - Начало: понедельник текущей недели (`today - timedelta(days=today.weekday())`) в `00:00:00`.
  - Конец: текущий день в `23:59:59`.
- В шаблоне `reports_sales.html` кнопка «Неделя» получает CSS-класс `active` благодаря проверке `{% if period == 'week' %}active{% endif %}`.
