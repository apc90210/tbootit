# Регламент наполнения справочника моделей (Reference Catalog Workflow)

Документ описывает стандартный порядок добавления новых моделей в Core-owned справочник моделей (`product_reference_models`) и правила их последующего применения.

---

## 1. Архитектурный принцип

Справочник моделей (**Reference Model**) хранит фабричные и типовые характеристики устройства:
- Бренд, модель, тип устройства;
- Типовая категория каталога;
- Технические характеристики (спецификации);
- Канонический заголовок и описание для сайта.

Конкретный экземпляр на складе (**Product / Stock Item**) хранит индивидуальные свойства:
- Цена закупки и продажи;
- Серийный номер, состояние, дефекты, заметки;
- Реальные фотографии;
- Принадлежность к категории «Техника под восстановление».

> **Главное правило безопасности**: Данные справочника **никогда не перетирают** индивидуальные свойства товара. Заполняются только отсутствующие (пустые) поля. Категория «Техника под восстановление» имеет абсолютный приоритет и никогда не заменяется модельным значением.

---

## 2. Способы добавления новой модели

### Вариант A. Создание через OWNER API / интерфейс управления

Используется для точечного заведения новой модели владельцем системы.

- **Эндпоинт**: `POST /api/product-reference/models`
- **Авторизация**: Требуются заголовки владельца (`X-Auth-Is-Owner: 1`, `X-Api-Token: <token>`).
- **Пример тела запроса**:
  ```json
  {
    "canonical_name": "HP LaserJet 1320",
    "brand": "HP",
    "model": "LaserJet 1320",
    "device_type": "printer",
    "default_category_id": 5,
    "specifications": {
      "Тип устройства": "Принтер",
      "Технология печати": "Лазерная",
      "Цветность печати": "Черно-белая",
      "Максимальный формат": "A4",
      "Двусторонняя печать": "Да",
      "Интерфейсы": "USB 2.0"
    },
    "site_title": "Лазерный принтер HP LaserJet 1320 б/у",
    "site_description": "Надёжный лазерный принтер с автоматической двусторонней печатью (дуплекс). Картридж Q5949A/X.",
    "aliases": [
      "HP LaserJet 1320",
      "HP 1320",
      "HP LJ 1320",
      "LaserJet 1320"
    ]
  }
  ```

---

### Вариант B. Пакетный JSON-импорт

Используется для массового импорта или обновления справочника (в том числе подготовленного через AI-research или внешние базы).

- **Файл каталога**: `data/reference_catalog/reference_models.json`
- **Эндпоинт**: `POST /api/product-reference/import?dry_run=false`
- **CLI-метод**: `python -c "import json; ..."` или вызов `import_reference_models_from_file(db, path, dry_run=False)`
- **Формат структуры**:
  ```json
  {
    "version": 1,
    "schema_version": "1.0",
    "models": [
      {
        "canonical_name": "Kyocera ECOSYS P2040dn",
        "brand": "Kyocera",
        "model": "ECOSYS P2040dn",
        "device_type": "printer",
        "category": "Принтеры",
        "aliases": [
          "Kyocera ECOSYS P2040dn",
          "Kyocera P2040dn",
          "ECOSYS P2040dn",
          "Kyocera 2040dn"
        ],
        "specifications": {
          "Тип устройства": "Принтер",
          "Технология печати": "Лазерная",
          "Цветность печати": "Черно-белая",
          "Максимальный формат": "A4",
          "Двусторонняя печать": "Да",
          "Сетевой интерфейс": "Да",
          "Wi-Fi": "Нет"
        },
        "site_title": "Лазерный принтер Kyocera ECOSYS P2040dn с дуплексом и сетью",
        "site_description": "Скоростной монохромный принтер с ресурсом фотобарабана 100 000 страниц."
      }
    ]
  }
  ```
- **Идемпотентность**: Импорт использует уникальный ключ `stable_key` (`brand|normalized_model`). Существующие модели обновляются без дублирования.

---

### Вариант C. Подтверждение существующего товара как источника модели (Promote / Learn)

Если конкретный товар в Core уже детально и безошибочно заполнен оператором (характеристики, описание, заголовок), его можно в один клик зафиксировать как эталон модели.

- **Эндпоинт**: `POST /api/product-reference/learn-from-product/{product_id}`
- **Тело запроса (опционально)**:
  ```json
  {
    "canonical_name": "Samsung NP355V5C",
    "custom_aliases": ["Samsung 355V5C", "NP355V5C"]
  }
  ```
- **Сервис**:
  1. Извлекает подтверждённые характеристики и бренд/модель из товара.
  2. Если товар находился в категории «Техника под восстановление», классификатор автоматически определяет истинную функциональную категорию для модели (например, «Ноутбуки»).
  3. Сохраняет эталон в справочник.
  4. Привязывает исходный товар к созданной модели с уверенностью `1.00`.

---

## 3. Поведение системы после добавления модели

Как только модель добавлена в справочник:
1. **Любое новое поступление товара**:
   - При создании вручную через Core UI;
   - При каноническом JSON-импорте;
   - При синхронизации объявлений с Avito;
   автоматически прогоняется через `product_reference_matcher`.
2. **Если совпадение однозначное (High Confidence >= 0.90)**:
   - Товар связывается с `reference_model_id`;
   - Заполняются пустые бренд, модель, категория (если не restoration), типовой заголовок и описание;
   - Объединяются характеристики (недостающие ключи подтягиваются из эталона);
   - Фиксируется аудит с деталями обогащения.
3. **Если найдена неоднозначность или это запчасть/партия**:
   - Автообогащение блокируется (`status: needs_review`);
   - Данные товара остаются в неприкосновенности до ручной проверки.
